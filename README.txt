האותיות של רפאל — הוראות התקנה

הקבצים בתיקייה (5 קבצים, כולם בתיקייה הראשית):
index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png

1. נכנסים ל-github.com ופותחים חשבון חינמי (אם אין).
2. לוחצים "New repository", נותנים שם (למשל rafael-letters), מסמנים Public, ו-Create.
3. לוחצים "uploading an existing file" ומעלים את 5 הקבצים. לוחצים Commit changes.
4. Settings ← Pages ← Source: Deploy from a branch ← Branch: main, תיקייה / (root) ← Save.
5. אחרי דקה-שתיים מופיעה כתובת: https://<שם-המשתמש>.github.io/rafael-letters/
6. בטאבלט: פותחים את הכתובת בכרום ← תפריט ⋮ ← "התקן אפליקציה" (או "הוספה למסך הבית").
7. פותחים מהאייקון פעם אחת עם אינטרנט. מאותו רגע המשחק עובד גם בלי רשת.

הקלטת קולות: באפליקציה המותקנת, לחיצה ארוכה על "להורים" ← הקלטות.
ההקלטות נשמרות בטאבלט עצמו. מומלץ לשמור גיבוי (כפתור "שמירת גיבוי").
קול עברי בלי אינטרנט: הגדרות ← נגישות ← המרת טקסט לדיבור ← Google ← התקנת נתוני קול ← עברית.
